# AGENTS.md

## Project context
A small research group is applying for an AI-safety research grant. The application needs a project summary, methodology, budget justification, and team bios, within strict word limits and using only facts the group has confirmed.

## Current task
Draft an AI-research grant application using only verified facts — leave any unknown field blank rather than inventing it.

## Phase
Plan

## How to work in this repo
- Use only the verified facts listed; mark everything else as [NEEDS APPLICANT INPUT].
- Do not exceed any section's word limit.
- Do not claim results, partnerships, or funding that are not in the verified facts.
- Draft prose only; do not submit anything or fill the funder's portal.
- Do not add applicant personal data beyond what is provided.

## Source-backed decisions
- **Never invent applicant facts** — Any figure, affiliation, date, or credential that isn't in the verified facts must be left as an explicit blank for the applicants to fill.
  - Why: A grant application is a factual, accountable document; a fabricated detail can void it and damage trust.
  - Tradeoff: The first draft will have visible gaps, which is correct — gaps are honest, invented facts are not.
- **Respect the funder's word limits per section** — Summary <= 200 words; methodology <= 500 words; each bio <= 100 words.
  - Why: Over-limit sections are commonly rejected unread.
  - Backed by: Funders routinely enforce per-section word limits and reject over-limit submissions (https://www.grants.gov/learn-grants/grant-writing)

## Tests and validation
A complete draft within every word limit, where each fact traces to the verified list and every unknown is an explicit, labelled blank — not an invention.

## Things not to change
- Inventing plausible-sounding metrics, affiliations, or prior awards.
- Padding a section to hit a word count with filler.

## When uncertain
Ask for clarification rather than changing unrelated areas.
